# 3주차 학습내용

  ## 1. ORM과 JPA

    ### ORM

        객체와 데이터베이스 테이블을 자동으로 매핑

        객체 - 데이터베이스 간 패러다임 차이 해결


    ### JPA

       자바 진영의 ORM 기술 표준
       
       개발자가 직접 JDBC를 다루지 않아도 JPA가 내부적으로 JDBC를 사용해 DB와 통신
    


  ## 2. JPA 동작 방식

    ### Entity Manager
    
     + 엔티티 객체를 데이터베이스와 연결

     + SQL을 직접 작성하지 않고도 엔티티를 데이터베이스에 등록/수정/조회/삭제 가능
     
     + 엔티티는 영속성 컨텍스트에 저장


    ### 영속성 컨텍스트

     + 엔티티를 관리하기 위한 가상의 공간

     + 1차 캐시 : 한 번 조회한 엔티티는 영속성 컨텍스트에 캐시되어, 같은 트랜잭션 내에서 다시 조회할때 DB 거치지않고 캐시에서 바로 반환

     + 변경 감지 : 1차 캐시에 저장된 엔티티의 최초 상태를 기억했다가 트랜잭션 커밋 시 현재 엔티티 상태와 비교하여 변경된 부분 있으면 자동으로 UPDATE 쿼리 생성하여 실행

     + 동일성 보장 : 같은 트랜잭션 내에서 동일한 엔티티를 여러 번 조회해도 항상 같은 객체 인스턴스를 반환

     + 트랜잭션을 지원하는 쓰기 지연


    ### 트랜잭션

     + 데이터베이스에 수행되는 작업의 단위

     + 여러개의 데이터베이스 연산을 하나의 논리적인 작업 단위로 묶어서 실행

     + 쓰기 지연 : 변경 사항들을 모아두었다가 트랜잭션이 커밋되는 시점에 한 번에 묶어 DB로 보내는 구조
